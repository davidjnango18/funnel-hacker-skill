# Funnel Taxonomy

Classify observed structures without forcing one label. A funnel may be `PLF/CPL + WhatsApp launch + high-ticket call`, or `advertorial + VSL + low-ticket + subscription`.

| Type | Observable indicators | Common nodes to look for |
| --- | --- | --- |
| direct-to-sale | Ad/content points directly to offer or PDP | ad, sales page/PDP, checkout, follow-up |
| advertorial | Editorial pre-sell before offer | native ad, article, CTA, sales page |
| VSL | Video is the primary sales argument | VSL host, delayed CTA, order page |
| webinar | Scheduled teaching/event precedes pitch | registration, confirmation, reminders, event, replay, offer |
| evergreen webinar | Automated or recurring webinar path | time selector, simulated/live cues, evergreen replay |
| PLF/CPL | Sequenced pre-launch content and bounded cart window | opt-in, CPL/PLC 1–3, transition, Open Cart, close |
| challenge | Multi-day participation produces commitment | signup, daily tasks, community, live/session, offer |
| lead magnet | Asset exchange precedes nurture | opt-in, delivery, email/WhatsApp nurture, offer |
| WhatsApp launch | WhatsApp group/channel carries material sequence | invite, group history, reminders, event/offer links |
| email launch | Email is the primary timed sequence | pre-launch emails, open, objection handling, close |
| quiz | Answers segment or personalize the next step | quiz, results, recommendation, offer/application |
| application | Qualification precedes sale | application, review, booking, call, close |
| book-a-call | Calendar is the primary conversion | page, form/calendar, confirmation, sales call |
| high-ticket call | Human sales conversation closes offer | application, qualification, booking, call, follow-up |
| low-ticket | Low-friction front-end purchase | direct offer, checkout, bump, upsell |
| tripwire | Low-cost offer converts a lead into a buyer | lead source, low-cost offer, ascension |
| ecommerce PDP | Product-detail page carries the offer | collection/ad, PDP, cart, checkout, post-purchase |
| upsell/downsell | Post-decision branch changes basket/value | bump, OTO, decline path, downsell, thank-you |
| subscription | Recurring billing/continuity is central | plan choice, trial, checkout, onboarding, retention |
| hybrid | Two or more patterns materially coexist | document each component and its confidence |

## Classification Rules

- Cite the indicators supporting each label.
- Record confidence and alternatives.
- Classify the observed version and market; do not assume other locales share it.
- A missing node does not disprove a type when the evidence is partial.
- Do not create a canonical edge unless a click, redirect, message link, timestamp, or other evidence supports it.
