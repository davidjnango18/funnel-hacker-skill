# PLC3 – Ownership / Experience / Владение

Шаблон для третьего Pre-Launch видео + тизера Cart Open. Самый важный ролик – на нём строится конверсия.

## Видео-сценарий PLC3 (40-60 минут)

```
[0:00 – 5:00] HOOK + RECAP PLC1+PLC2
- Сшить три видео в одну историю: возможность → метод → результат
- Сказать, что сегодня покажу, как это уже выглядит у тех, кто прошёл путь

[5:00 – 25:00] ГЛУБОКОЕ ПОГРУЖЕНИЕ
- Самый плотный кусок контента
- Конкретный навык / технику / часть метода, которую можно применить сразу
- Это «жирная» часть, после которой думают «если бесплатно так, что же платно»

[25:00 – 40:00] ДЕМО РЕЗУЛЬТАТА
- Покажи, как УЖЕ выглядит жизнь / бизнес / навык того, кто прошёл путь
- Видео-туры, скриншоты, диалоги, цифры
- 2-3 разных «после» – чтобы аудитория увидела себя в одном из них

[40:00 – 50:00] АДРЕСАЦИЯ ВОЗРАЖЕНИЙ
- «У меня не получится»
- «Нет времени»
- «Слишком дорого»
- «Уже пробовал»
Каждое возражение – один блок, обработать через историю или логику.

[50:00 – 55:00] ТИЗЕР ОФФЕРА
- «Завтра в [время] открою доступ к программе, где мы делаем это вместе»
- Будет [N мест] / [N дней]
- Не давать цену, не давать прямую ссылку – только «следи за каналом завтра»

[55:00 – 60:00] ФИНАЛЬНЫЙ CTA
- Включи уведомления / будь на месте к моменту открытия
- «Если хочешь зайти – будь готов завтра в [время]»
```

## Анонс PLC3 в день публикации

**Subject line / заголовок поста (примеры):**
- `PLC3 – самое важное видео`
- `[Имя], завтра я открою доступ`
- `Третье видео + тизер того, что будет завтра`

**Тело:**

```
[Имя],

PLC3 готов – это финальное видео серии.

Внутри:
– Глубокий разбор [конкретного куска метода] – можно применять прямо сейчас
– Демо: как выглядит [результат] у тех, кто уже прошёл путь
– Ответы на главные возражения, которые я слышал в комментах

Плюс – тизер того, что я открою завтра.

Смотреть: [ссылка]

Завтра в [время] я открою доступ к [название программы]. Будет ограниченное количество мест / окно открытия [N дней].

Если хочешь попасть – будь на канале / в почте к [время].

[Подпись]
```

## Промежуточный пост (PLC3 + 12 часов до Cart Open)

**Цель:** предельное anticipation за несколько часов до старта.

**Структура:**

```
[Имя],

Через [N часов] я открою регистрацию на [название].

Что внутри программы (тизер):
– [Главный модуль 1]
– [Главный модуль 2]
– [Главный модуль 3]
– [Бонус, доступный только в этом потоке]

Места: [количество] / Окно открытия: [N дней]

Цена и подробности – завтра в [время].

Включи уведомления, чтобы не пропустить.

[Подпись]
```

## Промежуточный пост (PLC3 + 1 час до Cart Open)

**Структура (короткий пост-тизер):**

```
Через час открываю регистрацию.

[Кратко: что внутри, кому подходит, лимит]

[Подпись]
```

## Чек-лист готовности PLC3

- [ ] Видео не короче PLC2 (это самый важный ролик)
- [ ] Recap PLC1+PLC2 в первые 5 минут
- [ ] Глубокий блок контента (15-20 минут плотного материала)
- [ ] Демо реальных «после» (2-3 разных)
- [ ] Адресованы 4 главных возражения
- [ ] Тизер оффера (без цены, без прямой ссылки)
- [ ] Финальный CTA «будь на месте к моменту открытия»
- [ ] Анонс PLC3 готов
- [ ] Тизерный пост за 12 часов до Cart Open готов
- [ ] Тизерный пост за 1 час до Cart Open готов
