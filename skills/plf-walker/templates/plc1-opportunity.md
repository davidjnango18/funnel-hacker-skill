# PLC1 – Opportunity / Возможность

Шаблон для первого Pre-Launch видео и сопровождающих анонсов.

## Видео-сценарий PLC1 (20-40 минут)

```
[0:00 – 2:00] HOOK
Открывающая сцена / неожиданная история / провокационный вопрос.
Пример: «Я только что увидел, как [конкретный человек] сделал [конкретный результат] за [неожиданный срок]. И я понял, что окно возможностей открылось прямо сейчас, и большинство людей это пропустит.»

[2:00 – 5:00] КТО Я
- Имя, чем занимаюсь
- Что у меня было раньше + что сделано сейчас (через результат, не через регалии)
- Почему я говорю про эту тему

[5:00 – 15:00] БОЛЬШАЯ ИДЕЯ
- Что изменилось в индустрии / технологии / поведении
- Почему старые подходы перестали работать
- Конкретные примеры сдвига

[15:00 – 25:00] ДОКАЗАТЕЛЬСТВА
- 2-3 факта/данных
- 1-2 истории людей, которые уже сделали этот сдвиг
- Тренды, которые подтверждают, что окно открыто сейчас

[25:00 – 35:00] ГЭП «КАК ЕСТЬ → КАК БУДЕТ»
- Где ты сейчас (с какими ограничениями живёшь)
- Где ты можешь быть (что станет доступно)
- Между этими точками – конкретный путь, я покажу его в следующих видео

[35:00 – 40:00] CLIFFHANGER + CTA
- «Завтра/в [дата] выйдет PLC2, где я покажу [конкретный метод]»
- «Подпишись на [канал/email] чтобы не пропустить»
- «Напиши в комментариях, что зацепило – я отвечу каждому»
```

## Анонс PLC1 в день публикации

**Subject line / заголовок поста (примеры):**
- `Это видео может изменить всё – PLC1 уже готов`
- `[Имя], у меня для тебя что-то важное`
- `Я работал над этим 3 месяца. Сегодня показываю первое видео`

**Тело (200-400 слов):**

```
[Имя],

[1-2 предложения личной истории – почему ты делаешь этот запуск]

Я только что выложил первое видео из серии. Там нет продажи. Там – большая идея, которая изменит твоё отношение к [теме].

Что внутри:
– [Тезис 1, без спойлера]
– [Тезис 2]
– [Тезис 3]

Смотреть здесь: [ссылка на видео]

Через [N дней] выйдет PLC2 – там я разберу метод по шагам.

Напиши в комментариях, что зацепило – я отвечу каждому.

[Подпись]

P.S. Это первое из трёх видео. Если хочешь видеть всю серию – [подпишись на канал / зарегистрируйся / включи уведомления].
```

## Промежуточный пост (PLC1 + 24 часа)

**Цель:** догреть тех, кто не открыл, и социально подтвердить тех, кто уже посмотрел.

**Структура:**

```
[Имя],

Вчера я выложил PLC1 – «[название]».

За первые сутки [N просмотров / N комментариев / N людей зарегистрировались]. Вот один комментарий, который меня зацепил:

> «[Цитата реального комментария]» – [Имя]

Если ещё не посмотрел: [ссылка]

Главная мысль PLC1 в одном предложении: [одна фраза, которая суммирует]

Завтра выйдет PLC2 – там покажу метод по шагам. Будет [N минут] плотного контента.

[Подпись]
```

## Чек-лист готовности PLC1

- [ ] Видео не длиннее 40 минут
- [ ] В первые 2 минуты есть hook, который удержит внимание
- [ ] Большая идея сформулирована за 15 минут
- [ ] Есть как минимум 2 примера или кейса
- [ ] Cliffhanger ведёт к PLC2 с конкретной датой
- [ ] CTA на комментарий или подписку
- [ ] Не упоминается продукт / цена / кнопка покупки
- [ ] Анонс-пост готов к публикации
- [ ] Промежуточный пост (через 24 часа) готов
