# PLC2 – Transformation / Трансформация

Шаблон для второго Pre-Launch видео + анонсов.

## Видео-сценарий PLC2 (30-50 минут)

```
[0:00 – 3:00] HOOK + RECAP PLC1
- Напомнить большую идею из PLC1 в 1-2 предложениях
- Сказать, что сегодня раскроем «как именно»

[3:00 – 20:00] МЕТОД / FRAMEWORK
- Назвать метод (важно – название превращает идею в продукт)
- 3-7 шагов с описанием каждого
- Для каждого шага – пример или мини-демонстрация

[20:00 – 30:00] КЕЙС №1
- Кто этот человек до программы (точка А)
- Что было больно
- Что сделал внутри (применил метод)
- Что получилось (точка B – конкретные цифры/факты)

[30:00 – 40:00] КЕЙС №2 ИЗ ДРУГОГО СЕГМЕНТА
- Если кейс №1 был про предпринимателя – №2 про сотрудника, или наоборот
- Цель – расширить применимость метода

[40:00 – 45:00] ЧТО ЭТО ЗНАЧИТ ДЛЯ ТЕБЯ
- Адаптация метода к ситуации зрителя
- Какие шаги можно начать сейчас, бесплатно

[45:00 – 50:00] CLIFFHANGER + CTA
- «В PLC3 [дата] я покажу, как это выглядит, когда ты идёшь по пути полностью»
- «И что именно будет внутри программы – тизер»
- CTA на комментарий
```

## Анонс PLC2 в день публикации

**Subject line / заголовок поста (примеры):**
- `PLC2 готов: вот сам метод`
- `[Имя], второе видео уже выложил. Метод внутри.`
- `Это самое полезное видео из всей серии – PLC2`

**Тело:**

```
[Имя],

PLC2 на месте.

Если PLC1 был про «почему сейчас», то PLC2 – про «как именно».

Внутри:
– Метод [название] – [N] шагов
– Кейс [имя]: [результат за срок]
– Кейс [имя]: [результат за срок]
– Что ты можешь начать применять уже сегодня, бесплатно

Смотреть: [ссылка]

Через [N дней] выйдет PLC3 – самое плотное видео и тизер того, что я открою на следующий день.

Напиши, что заходит больше: [метод сам по себе] или [кейсы]?

[Подпись]
```

## Промежуточный пост (PLC2 + 24 часа)

**Структура:**

```
[Имя],

Вчера выложил PLC2 – «[название]» с методом и двумя кейсами.

Самый частый вопрос за сутки:

> «[Реальный вопрос из комментов]»

Короткий ответ: [1-2 предложения]

Полный разбор будет в PLC3 – туда же положу демо, как метод выглядит изнутри. Видео выйдет [дата].

Если ещё не смотрел PLC2: [ссылка]

[Подпись]
```

## Чек-лист готовности PLC2

- [ ] Видео не длиннее 50 минут
- [ ] Метод назван (есть конкретное имя)
- [ ] 3-7 шагов метода, каждый с примером
- [ ] Минимум 2 реальных кейса с цифрами
- [ ] Кейсы покрывают разные сегменты аудитории
- [ ] Адаптация метода к зрителю в финале
- [ ] Cliffhanger ведёт к PLC3 с датой
- [ ] Не упоминается продукт / цена
- [ ] Анонс-пост готов
- [ ] Промежуточный пост готов
