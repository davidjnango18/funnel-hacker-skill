# JV Launch – запуск через партнёров

Самый масштабный вариант PLF: партнёры (Joint Venture, JV) рекомендуют твой запуск своим листам в обмен на комиссию. Уокер описывает JV как «следующий уровень» после Internal Launch.

## Когда использовать JV Launch

- Уже прошёл 1-2 успешных Internal Launch
- Есть прогретая аудитория и кейсы
- Хочешь масштабировать выручку x10 от Internal
- Готов делиться комиссией (30-50%) с партнёрами
- Есть инфраструктура для отслеживания партнёрских продаж

## Цели JV Launch

- Масштабная выручка (часто x5-x10 от Internal)
- Расширение листа за счёт лидов от партнёров
- Установление отношений с партнёрами для будущих запусков
- Brand-эффект – партнёры рекомендуют, что повышает доверие

## Архитектура JV Launch

```
Ты (Author) → создаёшь оффер, PLC, swipe copy
       ↓
Партнёры (JVs) → промотируют твой запуск своим листам
       ↓
Их аудитория → попадает на твою регистрацию
       ↓
Конверсия → ты считаешь продажи и платишь комиссию партнёрам
```

## Структура JV Launch (стандартная)

| Фаза | Длительность | Что делаем |
|---|---|---|
| JV Recruitment | 2-3 месяца до запуска | Поиск партнёров, переговоры, контракты |
| Affiliate Pre-Pre | 4-6 недель | Подготовка swipe copy для партнёров |
| Pre-Launch | 10-14 дней | Партнёры и ты – оба гонят трафик на PLC |
| Open Cart | 7-10 дней | Партнёрский трафик + твой |
| Post-Launch | 4-6 недель | Onboarding + расчёт комиссий |

## JV Recruitment (поиск партнёров)

**Где искать:**
- Авторы / инфлюенсеры с похожей аудиторией, не конкурирующие напрямую
- Бывшие клиенты с большой аудиторией
- Партнёры по предыдущим коллаборациям
- Через JV-сети / биржи

**Что предлагать:**
- 30-50% комиссия с продаж по их ссылке
- Бонусы для топ-партнёров (top JV получает дополнительную премию)
- Эксклюзивный bonus для аудитории партнёра (лимитированный)
- Готовые swipe copy / баннеры / видео

**Контракт:**
- Процент комиссии
- Период cookie attribution (обычно 30-60 дней)
- Условия выплаты (после refund period)
- Что партнёр обязан сделать (минимум N касаний к листу)

## Что нужно подготовить для партнёров

### JV Affiliate Center / Promo Page

Закрытая страница / бот для партнёров с:
- Swipe copy для каждой фазы (Pre-Launch, PLC1, PLC2, PLC3, Open Cart, Cart Close)
- Баннеры и графика
- Партнёрские ссылки с уникальным ID
- Реалтайм-статистика продаж и комиссий
- Календарь запуска с датами и временем касаний

### Swipe Copy

Готовые тексты для каждой фазы, которые партнёр может скопировать или адаптировать. **Важно:** дать варианты. Партнёр не будет писать сам, но и не должен публиковать ровно то же, что и ты – аудитория почувствует копипасту.

**Структура swipe pack:**
- 2-3 варианта анонса PLC1 (короткий / средний / длинный)
- 2-3 варианта анонса PLC2
- 2-3 варианта анонса PLC3
- 5-7 вариантов постов для Open Cart
- 3-4 варианта Cart Close crescendo

### JV Webinar / Кикофф

За 2-4 недели до старта PLC1 – закрытый эфир для партнёров:
- Что внутри запуска
- Какой оффер и цена
- Какая ожидаемая конверсия
- График касаний с датами и временем
- Q&A

Цель: партнёры понимают продукт и готовы продавать.

## Pre-Launch с JV

В Pre-Launch партнёры **дублируют твои PLC** на свои каналы:
- Ты публикуешь PLC1 в день -7
- Партнёр публикует свой пост-анонс PLC1 со ссылкой по их affiliate-ID
- Аудитория партнёра идёт на твой PLC1, регистрируется по партнёрской ссылке
- Все последующие продажи этому пользователю – засчитываются партнёру

**Ключевая механика:** партнёр гонит свой лист на твою серию PLC, а не на свой контент. Партнёр не делает свои PLC.

## Open Cart с JV

В Open Cart все – ты и партнёры – льют трафик на одну sales-страницу.

**Координация:**
- Каждый день запуска – у партнёров готовый swipe copy для этого дня
- Особый акцент на финальный день crescendo: партнёры тоже делают 3-4 касания
- Реалтайм-leaderboard среди партнёров стимулирует активность

**Топ-партнёры:**
- Получают дополнительный бонус (например, +10% при N продаж)
- Получают индивидуальные swipe / интервью с тобой как «эксклюзив для их аудитории»

## Метрики JV Launch

| Метрика | Целевая |
|---|---|
| Количество активных партнёров | 5-50 |
| % конверсии партнёрского трафика | 3-8% (ниже чем internal, потому что аудитория «не своя») |
| EPC (earnings per click) для партнёра | $1-5 |
| Комиссия от валовой выручки | 30-50% |
| Чистая прибыль автора | 50-70% выручки после комиссий и расходов |

## Финансовая модель JV Launch

```
Валовая выручка = Σ (трафик_партнёра × конверсия × средний_чек) + твой_internal_трафик

Комиссии = Партнёрские_продажи × % комиссии (30-50%)

Чистая выручка = Валовая - Комиссии - Расходы
```

**Пример:**
- 10 партнёров × 5000 их аудитория × 4% конверсии × $500 = $1,000,000 валовой
- Комиссии 40% = $400,000
- Расходы 5% = $50,000
- Чистая выручка = $550,000

## Антипаттерны JV Launch

- **Слабый swipe copy.** Партнёры не будут писать сами – если копи слабая, они её не используют, и продаж не будет.
- **Нет реалтайм-stats для партнёров.** Они не видят, что их трафик конвертится – охлаждаются.
- **Нет бонуса для топ-партнёров.** Без leaderboard / bonus тиров партнёры не выкладываются.
- **Конкурирующие партнёры.** Если два больших партнёра с одной аудиторией – они конфликтуют. Сегментируй.
- **Подвал по комиссии.** 20% комиссии – мало. Стандарт 30-50% для high-ticket products.
- **Cart продлили / изменили цену.** Партнёры теряют доверие быстрее, чем своя аудитория.

## Чек-лист JV Launch

**За 2-3 месяца до старта:**
- [ ] Список 20-50 потенциальных партнёров
- [ ] Контракты обсуждены и подписаны с 5-15
- [ ] Affiliate-инфраструктура (трекинг, статистика, выплаты)

**За 4-6 недель:**
- [ ] Swipe copy подготовлены (анонсы PLC + Open Cart 7 дней)
- [ ] Баннеры и графика готовы
- [ ] JV kickoff webinar проведён
- [ ] Партнёры залогинились в affiliate center

**За 1-2 недели:**
- [ ] Reminder для партнёров с графиком касаний
- [ ] Финальный swipe pack
- [ ] Дополнительные бонусы для аудитории партнёров

**Во время запуска:**
- [ ] Daily updates для партнёров (sales, top-of-leaderboard)
- [ ] Поддержка партнёров через прямой канал
- [ ] Индивидуальные ad-hoc swipes для топ-партнёров

**После запуска:**
- [ ] Расчёт комиссий
- [ ] Выплата (после refund period, обычно 30-60 дней)
- [ ] Отчёт для партнёров (что сработало, какая конверсия)
- [ ] Запрос обратной связи для следующего цикла
