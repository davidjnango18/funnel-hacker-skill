# PLF в Telegram-канале

Адаптация PLF под русскоязычные Telegram-каналы и закрытые листы ожидания. Email-листа нет, но есть подписчики канала + бот / форма для сбора контактов.

## Что меняется по сравнению с email-PLF

| Аспект | Email PLF | Telegram PLF |
|---|---|---|
| Лист | Email-адреса | Подписчики канала + закрытый канал листа ожидания |
| Касание | Письмо | Пост в канале |
| Видео | Embed в email | Видео-пост или ссылка на YouTube |
| Track open | Open rate | Просмотры поста (примерно) |
| Track click | Click rate | UTM на ссылках |
| Урок продаж | Sales page | Пост со ссылкой на оплату |
| Чат участников | Skool / Circle | Закрытая группа в Telegram |

## Архитектура каналов

Минимальная инфраструктура для PLF в Telegram:

1. **Основной публичный канал** – широкая аудитория. Сюда идут PLC1, PLC2, PLC3 и Open Cart посты.
2. **Закрытый канал «Лист ожидания»** – для подписавшихся через форму. Получают ссылку на бронь раньше основной аудитории + дополнительные бонусы / скидку.
3. **Бот для сбора лидов** – собирает email + Telegram username в БД (Supabase / Google Sheets).
4. **Чат участников** – доступен после оплаты.

## Pre-Pre-Launch в Telegram

**Активности:**
- Лид-магнит на сайте / лендинге → форма → закрытый канал листа ожидания
- Контент в основном канале на тему запуска (за 4-6 недель до Pre-Launch)
- Опросы в канале / историях / сторис → собираем боль аудитории
- Публикация результатов опросов как контент

**Готовность к Pre-Launch:**
- Закрытый канал листа ожидания: минимум 50 человек для seed, 200+ для internal
- Основной канал прогрет постами на тему

## Pre-Launch в Telegram (PLC1, PLC2, PLC3)

**Формат:** видео-пост в канале + длинный текст-разбор (на случай если не смотрят видео).

**Структура поста PLC:**

```
[Видео / ссылка на YouTube]

[Заголовок – большая идея PLC]

[Текст 500-1500 слов: ключевые тезисы из видео в текстовом формате]

[Якорь на следующее видео – «PLC2 выйдет [дата]»]
```

**Зачем дублировать видео текстом:** в Telegram люди часто читают, не смотрят видео. Текст с тезисами позволяет «потребить» PLC даже без просмотра.

**Промежуточные посты между PLC:**
- Скриншот лучшего комментария + твоя реакция
- Цитата из ответа на опрос
- Личная история, связанная с темой PLC

## Open Cart в Telegram

**День 0:**

```
[Видео или картинка – баннер запуска]

[Название] открыт.

[1-2 предложения: что это]

Что внутри:
– [Модуль 1]
– [Модуль 2]
– [Модуль 3]
– [Бонус для первого окна]

Цена: [сумма]
Места: [количество]
Закрытие: [дата + время]

Зайти: [ссылка с UTM]

PS Вопросы – в комменты или в личку.
```

**Эксклюзив для листа ожидания:**
- Пост в **закрытом** канале листа ожидания публикуется **раньше**, чем в основной канал (за 1-3 часа)
- В нём – особые условия: дополнительная скидка / бонус / приоритетный доступ
- В основном канале – стандартное открытие позже

Это отрабатывает «фору» для тех, кто заранее зарегистрировался.

**Дни 1-6:** см. `templates/cart-open-sequence.md`. В Telegram каждое касание – отдельный пост.

**Финальный день:** см. `templates/cart-close-crescendo.md`. 3-4 поста за 24 часа.

## Особенности Telegram-канала

### Алгоритм просмотров

В Telegram нет «inbox» как в email. Пост видят те, кто открыл канал в нужный момент или включил уведомления. Это значит:
- **Время публикации важно.** Утро (9-11 МСК) и вечер (19-21 МСК) – пиковые часы для русскоязычной аудитории.
- **Дублируй главные посты в нескольких форматах.** Картинка + текст + ссылка – охватывает разных потребителей.
- **Пин-пост на день** – важные посты Open Cart можно закреплять на сутки.

### Длина поста

Telegram режет посты длиннее 4096 символов. Большие посты (особенно sales-страница в день 0) – через серию постов или через ссылку на лендинг.

### Видео в канале

- Native Telegram-видео (загруженное в канал) – воспроизводится без выхода. Лучше для коротких роликов до 5-10 минут.
- YouTube-ссылка – для длинных PLC. Открывается в браузере или приложении YouTube.
- Telegram-видео + текстовая транскрипция → лучшая комбинация для PLF.

### Комментарии и обсуждение

Включи комментарии под постами Pre-Launch и Open Cart. Это:
- Создаёт публичное социальное доказательство
- Даёт сигнал, какие вопросы задают чаще
- Прогревает «холодных» зрителей через активность других

### UTM-метки

Все ссылки – с UTM. Минимум:
- `?utm_source=telegram`
- `?utm_medium=plc1` (или `cart_day1`, `cart_close`)
- `?utm_campaign=launch_<название>`

Это позволяет потом считать конверсию каждого касания.

## Чек-лист готовности для Telegram-PLF

**Инфраструктура:**
- [ ] Основной канал + закрытый канал листа ожидания
- [ ] Лид-магнит и форма сбора в закрытый канал
- [ ] Бот / сервис для регистрации (Supabase / Google Sheets)
- [ ] Платёжная страница с UTM-трекингом
- [ ] Чат участников (доступ после оплаты)

**Контент:**
- [ ] PLC1, PLC2, PLC3 видео + текстовые версии
- [ ] Промежуточные посты между PLC
- [ ] 7 дней Open Cart постов (см. templates/)
- [ ] Финальный день crescendo (3-4 поста)
- [ ] Welcome-пост для купивших
- [ ] Replay / non-buyer follow-up

**Триггеры:**
- [ ] Authority – через кейсы и демонстрацию
- [ ] Reciprocity – через PLC контент
- [ ] Anticipation – через cliffhanger и countdown
- [ ] Social Proof – через комментарии и кейсы
- [ ] Scarcity – лимит мест или дата закрытия
- [ ] Events – точная дата + время Open Cart

## Антипаттерны Telegram-PLF

- **Нет закрытого канала листа ожидания** → теряешь возможность дать «фору» лояльной аудитории
- **PLC только видео без текста** → теряешь тех, кто читает а не смотрит
- **Один пост на весь Open Cart** → теряешь 60-70% продаж
- **Нет UTM-меток** → не понимаешь, какое касание сработало
- **Чат участников запускается только после Cart Close** → купившие в день 0 сидят неделю в пустом чате, теряют интерес
